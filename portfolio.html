04 — Projects

Selected work.

Five systems, five different problems — a common thread of retrieval, learning, and deployment running through each.

01
RAG-Based YouTube Chatbot
A conversational agent that answers questions from YouTube video content — extracting and indexing transcripts in a vector database, retrieving relevant segments, and combining them with an LLM for context-aware answers.
02
AI-Powered Application Tracking System
A resume screening platform powered by Gemini that parses resumes, extracts skills and experience, and benchmarks them against job descriptions with a compatibility score and prioritized missing-keyword list.
03
Real vs. AI-Generated Art Detection
A binary image classifier distinguishing human-created from AI-generated artwork, using CNNs for feature extraction and GAN-based augmentation to strengthen performance on underrepresented classes.
04
Pakistan Stock Exchange Closing Price Prediction
A supervised regression pipeline forecasting daily PSX closing prices — data collection, EDA, technical-indicator feature engineering, and comparison of Linear, Random Forest, and Gradient Boosting models via RMSE/MAE.
05
Lang-AI: Multilingual Detection & Translation
A web NLP app that identifies input-text language and translates it on demand, using a TF-IDF + Naive Bayes classifier trained across dozens of languages, wrapped in a clean Streamlit interface.

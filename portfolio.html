AI-Powered Application Tracking System

A binary image classifier distinguishing human-created from AI-generated artwork, using CNNs for feature extraction and GAN-based augmentation to strengthen performance on underrepresented classes.

A web NLP app that identifies input-text language and translates it on demand, using a TF-IDF + Naive Bayes classifier trained across dozens of languages, wrapped in a clean Streamlit interface.
